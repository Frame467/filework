# วิธีลอง Commerce Operations

1. เปิด START.cmd แล้วเข้า http://localhost:4181
2. เลือกบัญชีคุณลูกค้าจากเมนูด้านบน เลือกสินค้า ใส่ตะกร้า ปรับจำนวน และไปหน้าสั่งซื้อ
3. ใช้ข้อมูลตัวอย่างแล้วกดยืนยันคำสั่งซื้อจำลอง ดูผลในออเดอร์ของฉัน
4. สลับเป็นมิน (staff) เข้าเมนูหลังบ้าน → ออเดอร์ → เริ่มจัดของ → ยืนยันจัดส่ง
5. ถ้ารับคืนสินค้าหรือยกเลิกก่อนส่ง ระบบเพิ่มสต๊อกคืน โดยไม่สามารถทำซ้ำกับออเดอร์เดิมได้
6. สลับเป็นอเล็กซ์ (admin) เพื่อแก้สินค้า ราคา สต๊อก ซ่อนสินค้า และเพิ่มพนักงาน

ข้อมูลทั้งหมดบันทึกในฐานข้อมูลของเครื่องนี้ บัญชีเดโมสลับได้โดยไม่มีรหัสผ่าน การชำระเงินและการจัดส่งเป็นการจำลอง
